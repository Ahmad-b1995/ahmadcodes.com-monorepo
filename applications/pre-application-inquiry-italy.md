# Pre-application inquiry — Italian universities

Send a tailored version of this email to each Italian university you're
targeting BEFORE you formally apply via Universitaly. The goal is to confirm
your profile is eligible so you don't burn an application slot.

Send each university separately. Never BCC. Never bulk-send.

## What each reply means

| Reply | Action |
|---|---|
| "Yes, please proceed with the formal application." | Apply with confidence. Save the email. |
| "Yes, but we recommend X." | Do X. Then apply. Note: TOLC-I and language certs are the most common requests. |
| "Your profile is not eligible because…" | Drop this university. Move resources to the others. |
| No reply within 3 weeks | Follow up once politely. If still no reply, treat as "low priority" and apply anyway if deadlines force it. |
